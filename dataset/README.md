# ScholarHAAB Dataset Workspace

This folder is the auditable workspace for lawful, permitted, or user-provided academic sources.

Do not commit downloaded PDFs, extracted text JSONL, embeddings, or generated logs. The committed files here are only structure/readme placeholders so the pipeline has predictable paths.

Required proof files generated by the scripts:

- `dataset/manifests/sources_manifest.jsonl`
- `dataset/manifests/papers_manifest.jsonl`
- `dataset/logs/download_attempts.jsonl`
- `dataset/failed/download_failures.jsonl`
- `dataset/failed/extraction_failures.jsonl`
- `dataset/reports/coverage_report.json`

Honesty rule: ScholarHAAB is not allowed to claim complete coverage unless the coverage report proves it.
