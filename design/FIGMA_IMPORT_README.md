# ScholarHAAB Figma Import

Generated design artifact:

- `design/ScholarHAAB-figma-import.svg`

## How to Use in Figma

1. Open Figma.
2. Drag `ScholarHAAB-figma-import.svg` onto the canvas.
3. Right-click the imported board and choose `Ungroup` if you want to edit individual text, shapes, cards, and frames.
4. Rename the major groups as Figma frames:
   - Landing Page
   - Dashboard
   - Solver
   - QBank Mock Test
   - Docs Module
   - Design System

## Notes

This is a Figma-importable SVG design board, not a native `.fig` file. Figma does not expose a simple local `.fig` file format that can be generated safely from this workspace without using the Figma API or a Figma plugin.

The design is based on the current ScholarHAAB app code:

- `app/page.tsx`
- `app/dashboard/page.tsx`
- `app/solver/page.tsx`
- `app/qbank/page.tsx`
- `app/docs/page.tsx`
- `components/Logo.tsx`
